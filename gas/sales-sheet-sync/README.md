# 営業ダッシュボード連携（Google Apps Script）

Googleスプレッドシート「KINDLER 営業行動管理」の案件・商談を、営業ダッシュボードへ反映するための一時的な連携スクリプトです。

このコードは対象スプレッドシートのIDを使って開くため、30分ごとの自動実行時にも同じスプレッドシートへ反映されます。

## 最初の設定

設定には、営業ダッシュボード管理者から渡された連携用の鍵が必要です。鍵はこのREADMEやスプレッドシートのセル、スクリプト本文には書かないでください。

1. 対象のGoogleスプレッドシートを開きます。
2. 上部メニューの「拡張機能」→「Apps Script」を開きます。
3. Apps Script画面の `Code.gs` を開き、中身をすべてこのフォルダの `Code.gs` の内容に置き換えて保存します。
4. Apps Script画面左側の歯車アイコン「プロジェクトの設定」を開きます。
5. 「スクリプト プロパティ」まで下へ移動し、「スクリプト プロパティを追加」を押します。
6. プロパティに `SHEET_IMPORT_TOKEN`、値に管理者から渡された連携用の鍵を入力して保存します。
7. スプレッドシートの画面を再読み込みします。

再読み込みすると、上部メニューに「ダッシュボード連携」が表示されます。

## 初回の反映

1. 「ダッシュボード連携」→「今すぐ反映」を選びます。
2. 初回だけGoogleの承認画面が出るため、利用中のGoogleアカウントを選び、表示内容を確認して許可します。
3. 完了画面で、案件と商談の件数を確認します。
4. 「案件管理」の「ダッシュボードID」列と、「反映ログ」シートを確認します。

「案件管理」の2行目に「ダッシュボードID」という見出しがない場合は、最初の案件IDを書き戻す前（新規案件がない場合は正常完了時）にQ列へ自動で追加されます。Q列に別の見出しがある場合は上書きせず、エラーで停止します。

新規案件のダッシュボードIDは、500行ごとの案件バッチが成功するたびにQ列へ書き戻されます。後続の案件バッチや商談の送信が失敗しても、それまでに書き戻したIDは残るため、再実行時は続きから反映できます。

## 30分ごとの自動反映

「ダッシュボード連携」→「自動反映を設定（30分ごと）」を選びます。初回はGoogleの承認を求められることがあります。

停止するときは「ダッシュボード連携」→「自動反映を止める」を選びます。設定をやり直した場合でも、自動反映が重複して登録されないようになっています。

## シート入力時の注意

- 1行目はタイトル、2行目は見出し、3行目以降がデータです。
- 見出しの名前で列を判定するため、列の順番を変えても動作します。ただし、見出しの文字は変更しないでください。
- 「案件管理」は会社名が空の行を反映しません。
- 「商談履歴」は商談IDが空の行を反映しません。
- 商談の「顧客名 / 会社名」は、「案件管理」の会社名から始まるように入力してください。例：案件の会社名が「株式会社サンプル」なら、「株式会社サンプル 田中様」は紐づきます。
- 複数の会社名に一致する場合は、最も長く一致した会社名が使われます。
- 同じ商談IDは、何度反映しても二重登録されません。
- スクリプトが書き換えるデータセルは、「案件管理」の「ダッシュボードID」列だけです。

## 結果とエラーの確認

成功・失敗にかかわらず、「反映ログ」シートに1回につき1行記録されます。案件の新規・更新・エラー件数、商談の新規・登録済み・スキップ・エラー件数、行番号つきのエラー（先頭10件）を確認できます。失敗時の「エラー内容」には、失敗理由とその時点までの案件の新規・更新件数も記録されます。

主な確認ポイントは次のとおりです。

- `SHEET_IMPORT_TOKEN` が未設定：上の「最初の設定」をやり直してください。
- 「必要な見出しがありません」：2行目の見出しが元の文字と同じか確認してください。
- 担当がメンバーマスタにいない：シートの担当名をダッシュボードのメンバー名と揃えてください。
- 商談がスキップされた：商談の顧客名が案件の会社名から始まっているか、案件にダッシュボードIDがあるか確認してください。
- 通信・認証・サーバーエラー：失敗までに登録できた案件IDはQ列に残り、失敗理由は反映ログに記録されます。鍵と通信状況を確認してから、もう一度実行してください。

エラーが解消しない場合は、表示されたメッセージと発生時刻を営業ダッシュボード管理者へ伝えてください。鍵そのものは共有しないでください。

## この連携を撤去するとき

自動反映を止めてから、スプレッドシートにバインドされたApps Scriptを削除してください。ダッシュボード側のAPIと環境変数の撤去は、ダッシュボード管理者が行います。
